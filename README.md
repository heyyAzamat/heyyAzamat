### 🪪 Human ID
A verification platform for **AI likeness licences**. Turns a person’s grant into a
canonical document, fingerprints it with SHA-256, anchors the hash on Solana, and
serves a public certificate. Biometrics and contract contents never touch the chain —
only hashes.

`TypeScript` `Next.js` `Prisma` `Rust/Anchor` `Solana`

[Repo](https://github.com/heyyAzamat/human-id) · [Live demo](https://human-id-solana.vercel.app)

</td>
